Privacy Policy

Homeserver Backup is a personal tool used exclusively by its owner.

Data access

The application requests access to Google Drive with the drive.file scope only. This limits access to the files and folders the application itself creates in the owner's own Drive. It cannot read, modify or delete any other file.

Data collection and sharing

The application does not collect, store, share or sell any personal data. All backup data is encrypted on the owner's server before it is uploaded, and it is stored only in the owner's own Google Drive account.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
